# 16Agent・SubtaskSeparated 接触停止ルール (v2)

記録日: 2026-10-16

## 条件と元データ

- 学習run: `wh_middle2Gate_ST_16_v1_01`（trainer seed 1）、`_02`（seed 2）。
  各runはPPO、5,000万step、6環境 x 各16Agent。名前の `v1` はrun IDであり、使用Configの版は `STseparated_v2`。
- 両runの `unity_experiment.json` は同一のConfig内容ハッシュ、Environment Preset
  `Middle_2Gate_v1` の同一ハッシュを記録。各環境は60 x 60 m、棚12、ゲート2、棚全体のColliderあり。
- `STseparated_v2` は `SubtaskSeparated` / `Scalar` / `LegacyScalar9`。Agent接触罰は各Agent -5、
  接触停止1秒、壁接触罰-3、最大15,000 step。フェロモン分泌量1、100 FixedUpdateごとに5%蒸発、
  Scalarフェロモン報酬倍率0.0002。
- 推論: 最終ONNX、決定的推論、1環境 x 16Agent、固定シミュレーション時間300秒 x 各5試行、
  両モデルともtrial seed 1～5。`test_experiment.json` は両runでConfigとEnvironment Presetの
  ハッシュ一致を記録し、5試行すべて `simulation_duration_target` で終了した。
- 元データ: `results/wh_middle2Gate_ST_16_v1_{01,02}/` 内の `configuration.yaml`、
  `unity_experiment.json`、`test_experiment.json`、`logTest.csv`、`logTest_summary.csv`、
  `pheromone_trials/`。`results/` はGit管理外。

## 観察された事実

以下は5試行の平均値。括弧内は標準偏差。

| run | 完了タスク | tasks/分 | 壁接触 | 棚接触 | Agent接触 | 接触合計 | Agent非接触で完了 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `_01` | 235.2 (9.6) | 47.04 | 347.6 | 306.8 | 540.6 | 1,195.0 | 71.8 (6.7) |
| `_02` | 256.0 (7.1) | 51.20 | 365.2 | 351.8 | 479.8 | 1,196.8 | 78.4 (5.4) |

| trial seed | `_01` 完了 | `_02` 完了 | `_01` Agent接触 | `_02` Agent接触 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 233 | 247 | 560 | 500 |
| 2 | 246 | 266 | 494 | 464 |
| 3 | 218 | 260 | 644 | 478 |
| 4 | 238 | 258 | 539 | 455 |
| 5 | 241 | 249 | 466 | 502 |

- 同じtrial seedで対にすると、`_02` は5試行すべてで完了数が多い。合計は `_01` が1,176、
  `_02` が1,280で、差は+8.8%。Agent接触数は4/5試行で `_02` が少ないが、seed 5では逆転した。
- 完了1件あたりのAgent接触数は `_01` が約2.30、`_02` が約1.87。ただし壁・棚接触は
  `_02` のほうが多く、接触合計の平均はほぼ同じ。合計接触/完了の低下は完了数増加の影響を含む。
- `collision_free_completed_tasks` は**そのエピソードでAgent接触がなかった完了数**。
  壁・棚接触がなかったことは意味しない。完了に占める割合は `_01` が30.53%、`_02` が30.63%で近い。
- Agent接触列は接触した両Agent側で数えるため、物理的な接触ペアの件数ではない。
- フェロモンは48枚のサブタスクマップに記録され、5試行の活性map-cell割合は `_01` が
  8.34～9.44%、`_02` が7.94～8.65%。`_01` のtrial seed 3では単一セル最大値2,944.612と
  他試行より高い値があり、帰還側の「棚5→出口2」マップで見られた。

## 解釈・未検証

- 同一設定下でもtrainer seedによって搬送量と接触傾向に差が出た。2学習run・各5試行だけでは
  学習seedの一般的な効果や、フェロモン方式による混雑回避を結論できない。
- 完了数の増加とAgent接触数の減少は見られるが、Agent非接触で完了した**割合**はほぼ同じ。
  `_02` を「安全な方策」と断定せず、搬送量と接触回避を別々に評価する。
- フェロモンの活性セル数や局所最大値だけでは、経路の質や滞留の原因は分からない。
  特に `_01` のtrial seed 3の高濃度セルは軌跡・滞在時間との突き合わせが必要。
- 旧 `STseparated_v1` の16Agent推論は接触罰、停止時間、壁罰、最大stepが異なり、
  しかも各モデル1試行。今回の2runと単純比較して新ルールの効果とみなさない。

## 次の検証

1. 同じConfigでtrainer seed 3以降を追加し、学習seed間のばらつきを見る。
2. 新ルールを固定したまま、フェロモンなし条件を同じ学習・推論seed集合で作り、方式差を比較する。
3. Agent非接触の完了率に加え、接触ペア件数、停止時間、壁・棚接触を分けて評価する。
