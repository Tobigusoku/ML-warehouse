### 仮説（未検証）

`_01` と `_03` は搬送せず狭い領域に滞留する方策を学んだ可能性が高い。Scalarフェロモンは移動を条件にせず毎ステップ分泌され、訪問前のセル値に応じて `log(value + 1) * 0.0002` の報酬を得る。時間ペナルティは `-0.001/step` なので、セル値が約147を超えるとフェロモン報酬だけでこれを上回る。値1,899なら約`+0.00151/step`。分泌量1、100ステップごとに5%蒸発する設定も、同じ場所への反復分泌で高濃度になり得る。

このため「自分たちの分泌した濃い場所にとどまる」報酬ハックが疑われる。ただし、フェロモン報酬が学習失敗の主因と確定したわけではない。報酬以外の局所解、長いEpisode上限、タスクマップの細分化、学習時と推論時のフェロモン初期状態の違いも候補として残る。各モデルの推論はまだ1試行である。

### 次の切り分け

1. フェロモンの分泌・観測・蒸発は維持し、`pheromoneRewardScale = 0` だけを変更した新しいConfigでseed 1、2、3を再学習する。既存Configは上書きしない。
2. 元条件と同じtrial seed集合・時間・Agent数で推論し、達成数、滞留、活性セル、セル最大値を比較する。テスト結果を保存する際は `Skip Result Logging` をオフにする。
3. 滞留が残るなら、時間・タイムアウト報酬、移動条件付き分泌、マップ分割、初期フェロモン差を順に切り分ける。
