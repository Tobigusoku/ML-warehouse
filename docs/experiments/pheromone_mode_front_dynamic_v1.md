# 16Agent・None / SubtaskSeparated / TaskSeparated 比較

初回確認: 2026-10-23 (None/ST)。TaskSeparatedを追加: 2026-10-25。

## 目的・条件

- 問い: 現行のScalarフェロモンは、なしと比べて搬送・接触指標を改善するか。
  完全タスク単位とサブタスク単位の分割方式で差が出るか。
- None: `None_v2`、`wh_middle2Gate_none_16_v2_01`～`03`。
  ST: `STseparated_v4`、`wh_middle2Gate_ST_16_v4_01`～`03`。
  Task: `taskSeparated_v3`、`wh_middle2Gate_task_16_v3_01`～`03`。
- 3つのConfigアセットの差は名前・IDと `pheromoneMode` のみ。共通条件は
  `FrontDynamic19`、`LegacyScalar9`、`Middle_2Gate_v2`、16Agent、同じ移動・接触・報酬設定。
  学習記録上のEnvironment Presetハッシュも一致する。
- 入口2 x 棚12 x 出口2。Taskは `入口 x 棚 x 出口` の48マップを配送・帰還で共有。
  STは配送 `入口 x 棚` 24枚と帰還 `棚 x 出口` 24枚で計48マップ。
  今回はマップ総数が偶然同じで、蓄積する履歴の分け方が違う。
- 各条件ともPPO 5,000万step、trainer seed 1～3、6学習環境 x 各16Agent。
  各最終ONNXを決定的推論、1環境 x 16Agent、300シミュレーション秒 x
  trial seed 1～5で評価。全9件の `test_experiment.json` で学習Configとのハッシュ一致を確認。
- 元データは各runの `configuration.yaml`、`unity_experiment.json`、
  `test_experiment.json`、`logTest.csv`、`pheromone_trials/`。`results/` はGit管理外。

## 観察された事実

各値は15試行平均。Agent接触は接触ペアの開始イベント数。
非接触完了率は「Agent接触なしで完了したタスク数 / 全完了数」で、壁・棚接触は含まない。

| 方式 | 完了数 / 300秒 | Agent接触 | Agent接触 / 完了 | 非接触完了率 | 壁接触 | 棚接触 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| None | 371.7 | 164.9 | 0.444 | 71.2% | 162.0 | 460.2 |
| ST | 385.5 | 155.9 | 0.404 | 74.3% | 133.3 | 451.5 |
| Task | 383.7 | 153.3 | 0.400 | 74.8% | 138.5 | 446.7 |

各runの5試行平均。列は完了数 / Agent接触数 / Agent非接触完了数。

| trainer seed | None | ST | Task |
| ---: | ---: | ---: | ---: |
| 1 | 376.8 / 196.6 / 263.4 | 408.0 / 119.4 / 312.4 | 382.8 / 162.0 / 280.2 |
| 2 | 378.6 / 163.4 / 265.0 | 372.2 / 184.2 / 273.0 | 386.2 / 150.4 / 284.2 |
| 3 | 359.6 / 134.6 / 265.8 | 376.4 / 164.2 / 274.0 | 382.0 / 147.6 / 296.0 |

- Task対STの完了数差は平均-1.9件（Taskが0.5%少ない）、Agent接触差は
  平均-2.6件（Taskが1.7%少ない）。seed 1ではST、seed 2・3ではTaskのほうが
  完了数が多く、Agent接触が少ない。一定方向の優位性はない。
- None比ではTaskの完了数が平均+12.0件（+3.2%）、STが+13.9件（+3.7%）。
  Agent接触はTaskが-11.5件（-7.0%）、STが-8.9件（-5.4%）。
- フェロモン図の `summary.csv` を15試行で集計すると、48マップの平均有効セル率は
  ST 13.2%、Task 17.8%。マップ全体の値の合計はそれぞれ約28,606、28,599。
  Taskは配送・帰還で同じマップを使うため、セル率だけで情報の質は判断できない。
- 全45試行が300秒の `simulation_duration_target` で終了した。

## 解釈・限界

- この倉庫条件ではTaskとSTの最終推論成績はほぼ同等。seed 3件では、
  どちらの分割方式が優れているか結論できない。
- フェロモンあり2方式の平均はNoneよりやや良いが、効果量は小さく、
  学習seedごとの結果も一様でない。これだけで安定した改善とは言えない。
- Noneではフェロモン観測9値とフェロモン報酬がともにゼロになる。
  Task/STでは両方働くため、None比較から間接情報共有と追加報酬の寄与は分離できない。
- 同じtrial seedでも方策が違えば軌跡や乱数呼出順は変わる。
  平均有効セル率は試行終了時のマップ値であり、行動時に有用な値を読めた頻度ではない。

## 次の検証

1. マップごとの使用間隔と再訪時の残存量、Agentが読んだ周辺9セルの分布を測る。
2. 必要なら未使用時凍結や蒸発率を別Configで比較し、疎なサブタスクの履歴が
   消えすぎていないか確かめる。
3. フェロモン報酬0のTask/STを別Configで学習し、観測情報の寄与を切り分ける。
4. 追加trainer seedや異なるAgent密度・レイアウトで小差が再現するか検証する。
